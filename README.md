# 小宇家电维修 · 空调上门维修单页官网

面向本地家电维修小店的单页官网：六屏内容、手机优先响应式、在线咨询表单、基础 SEO 与微信分享卡片。纯静态，不用构建、不用服务器，改文案只改 `index.html`。

- **线上地址**：https://dablexy.github.io/ac-repair-site/
- **技术栈**：HTML5 + CSS3 + 原生 JavaScript（无框架、无依赖、无构建）
- **页面构成**：首屏 / 服务项目 / 维修案例 / 师傅介绍 / 常见问题 / 联系方式与表单

> 本仓库为前端作品演示：品牌、案例与配图为示例，联系方式为作者本人。页面页脚保留「练习项目」声明，不提供真实上门维修服务。

## 本地预览

不要直接双击 `index.html`（`file://` 下表单请求会被浏览器拦），起个本地服务：

```bash
python -m http.server 8000
# 浏览器打开 http://localhost:8000
```

## 已知限制

**微信转发缩略图不显示。** 2026-11-10 实测：同一链接发给好友，卡片能正确出现标题「小宇家电维修｜空调不制冷当天上门，先报价再动手」和网址，但右侧缩略图是灰图标。

已排除的原因：
- `og:image` 已是完整 https 地址，指向 `assets/img/share-card.jpg`，线上实测可打开、600×315、26 KB
- 换 `?v=2 / ?v=4 / ?v=5` 多次强制重抓，结果一致
- 大图（1200×630、105 KB）和小图（600×315、26 KB）都试过，均不出图

结论：微信的图片抓取服务访问不到 `github.io` 域名（境外托管 + 未备案），属于托管环境限制，与页面配置无关。页面本身、标题、描述、跳转均正常。

如需微信必出缩略图，把这张卡片图放到国内可访问的图床或对象存储，再改 `og:image` 指向新地址即可——**只改这一行，其余代码不用动**。

## 表单接收

表单用 **FormSubmit**（免费、免注册）转发到邮箱，接法只有 `assets/js/main.js` 里这一行：

```js
var FORM_ENDPOINT = "https://formsubmit.co/ajax/2470781363@qq.com";
```

换收件邮箱就是改这一行里的地址，其余代码不用动。三个要点：

1. **首次提交必须在邮箱里点激活。** 第一次有人提交时，FormSubmit 会给你发一封 `Activate Form` 邮件，点了之后才开始转发。不点的话，页面会提示「没提交成功」——这是故意的，避免给客户假的成功提示。
2. **邮件标题固定为「网站咨询｜小宇家电维修」**，在 `main.js` 的 `_subject` 字段里改，方便在邮箱里筛出来。
3. **客户看到的是「收到，我看到后会尽快回你电话」**，只有真正收信成功才显示；网络失败或服务异常时提示重新提交或直接打电话，不会清空已填内容。

`FORM_ENDPOINT` 留空时进入演示模式，页面会明写「这条信息并没有真的发出去」，适合没人接收的纯展示场合。
