# 小宇家电维修 · 单页官网（练习项目）

对应《项目需求说明书_企业单页官网》第 2 章交付范围：单页六屏、响应式、咨询表单、基础 SEO、上线部署。
品牌与案例内容为**虚构示例**（练习用）。电话、微信二维码已换成自己的；服务范围写的是「都江堰市区」（示例，按你实际能到的范围改）；配图为 AI 生成的示意图，不是真实拍摄。

## 怎么打开

1. 直接双击 `index.html`，浏览器就打开（不需要装任何环境）。
2. 想改一行就自动刷新：VS Code 装 `Live Server` 插件 → 右键 `index.html` → Open with Live Server。
3. 手机上看效果：电脑和手机连同一个 WiFi，Live Server 会给一个 `http://192.168.x.x:5500` 地址，手机浏览器输入即可。

## 已知未做（别当成 bug）

- 表单没有后端，`FORM_ENDPOINT` 为空时是演示模式，成功提示会明写「这条信息并没有真的发出去」。
- **页脚那行「本页为练习项目，品牌、案例与配图均为示例」是安全声明，别随手删。** 你现在的手机号和微信码是真的，但品牌、案例、师傅照片都是假的：留着这行，陌生人扫到只会当作品看；删了，就等于用编造的商家信息招揽真实客户，出事要担责。真交付给客户时，这行跟着客户的实际资质一起替换。
- 案例里的「40 分钟」「90 天保修」是示例文案，真实交付时按实际口径写，别留着。
- 没有做后台、多语言、在线支付，和说明书第 2.2 节「明确不做」一致。
- 二维码是**个人微信码**，页面上一公开，任何人扫码都能加你，可能会被推销号骚扰；真要对外发布建议换成企业微信或专门的接单小号。
- 手机上底部那条「立即咨询」是固定悬浮的，滑到联系区时会自动收起，避免和「提交」按钮叠在一起（main.js 里那段 IntersectionObserver）。
